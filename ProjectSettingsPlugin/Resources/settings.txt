# Descriptions of the elements of a Paratext Settings.xml, embedded in the plugin.
# One line per element: name | group | decoder | English | Spanish | French
# A '*' in the name matches any text (prefix*, *suffix); '{0}' in a description is the matched text.
# Exact names are looked up first, then the custom checks' .cms options, then the patterns.
# Groups and decoders: see SettingCatalog.cs. Empty decoder = plain text.
#
