Project Settings Report is a Paratext tool that shows all of a project's settings on one page in your web browser, each with a description in plain words. It also reads the language settings, and counts how often each approved character and punctuation mark occurs in the text, so you can see what is approved but never used, and what is disapproved but still in the text. It also shows the quotation marks, the number and Scripture reference settings, and the settings of the inventories. The report only shows the settings; you change them in Paratext.
